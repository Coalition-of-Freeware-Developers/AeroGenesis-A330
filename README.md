# AeroGenesis-A330
### AeroGenesis Airbus A330 for X-Plane 12

We are a small group of X-Plane developers who decided to rework Laminar Research's Airbus A330-300 for X-Plane 12.
After we got the approval from Laminar Research to modify their work and share it with the community we began to work on it - which was about half a year ago.

With the first beta and stable versions published and tested through our discord by more than 3000 members we decided it is time for the AeroGenesis A330-300 to be shared with the broad
X-Plane community.

So here it is - the AeroGenesis A330-300, currently on version 1.1.2 featuring visual upgrades, a custom Electronic Flight Bag (EFB), PW4000 and GE engine variants and much more.
You can download the newest versions on our [GitHub page here.](https://github.com/Coalition-of-Freeware-Developers/AeroGenesis-A330/releases)

Please note that this is a completely community-driven project which we all work on during our free-time. So it can't be perfect from the start on.
If you encounter any problems, have questions or want to chip-chat with our community you are kindly invited to [join our offical Discord here.](https://discord.gg/UWMf2CpMHJ)

There you can also have a look at our Work In Progress and receive updates on the project.



**Whish you all the best & always happy landings! <br>
The Team of AeroGenesis**

### Installation Guide:

To install the AeroGenesis A330 simply download the zip file from the release and copy the extracted folder somewhere into your X-Plane/Aircrafts folder.

#### MacOS:

Due to security settings on latest MacOS releases, some additional steps are required to get our Aircraft running for you. We gathered some documentation, but if you have installed other freeware addons previously, you might be familiar with the steps.

    
  [X-CRAFT "How to Run X-Plane Addons on any Mac System" Guide](https://www.xcrafts.com/how-to-install-add-ons-on-mac-apple)

  [Laminar Research "Fixing X-Plane 11 Privacy Permissions on MacOS Catalina" Guide](https://www.x-plane.com/kb/fixing-x-plane-11-privacy-permissions-on-macos-catalina/)

  [91P72 Guide on X-Plane.org Forum](https://forums.x-plane.org/index.php?/forums/topic/241705-is-current-version-of-x-plane-11-working-with-mac-os-big-sur-now-ive-been-waiting-to-upgrade-the-os/#findComment-2158446)

  [Stratosphere Studios - Readme Section Mac, 2nd bullet point "MacOS will block the plugins ..."](https://github.com/Stratosphere-Studios/777-300ER?tab=readme-ov-file#mac)
